v0.5.0 · Windows 10 / 11

smart-alt-tab
저시력 친화 창 전환기

Windows 기본 Alt+Tab을 큰 글씨·고대비로 대체합니다. Alt를 누른 채 Tab·방향키로 고르고, 놓으면 그 창으로 전환됩니다.

다운로드 exe · 약 10MB GitHub 저장소

설치 과정 없습니다. 받은 파일을 두 번 누르면 바로 실행됩니다. Python도 필요 없습니다.

왜 만들었나

Windows 기본 Alt+Tab은 창 제목 글씨가 작아, 저시력 사용자가 "지금 어느 창인지" 알아보기 어렵습니다.

게다가 Alt+Tab 전환기 내부의 하이라이트 이동은 표준 API로 공개되지 않아(실측 확인), "고르는 중 실시간으로 크게 보기"는 Alt+Tab을 통째로 대체해야만 가능합니다. smart-alt-tab이 바로 그 대체 전환기입니다.

주요 기능

큰 글씨·고대비

어두운 배경에 두꺼운 큰 글씨로 열린 창을 보여줍니다. 색만이 아니라 테두리·마커로도 선택을 표시합니다.

익숙한 조작

Alt 홀드 중 Tab / Shift+Tab / 방향키로 이동, Alt를 놓으면 전환. Esc로 취소, Enter로 즉시 확정.

다중 모니터

커서가 있는 모니터의 작업영역 중앙에 전환기를 띄웁니다.

정확한 창 목록

소유 팝업 체인을 추적해 대표 창만 표시 — 유령 창·중복 없이 깔끔하게.

안전장치

열린 창이 없으면 기본 Alt+Tab으로 자동 폴백, 키 유실 시에도 오버레이가 남지 않게 자동 확정.

DPI 인식

per-monitor v2 DPI로 고배율 화면에서도 또렷하게 렌더합니다.

내 눈에 맞게

트레이 아이콘 우클릭 → 설정에서 글꼴·글자 크기·언어(한국어/English/日本語/中文/Tiếng Việt)를 고르면 바로 적용됩니다.

사용법

  1. 내려받기 — 위 다운로드 버튼을 누르면 smart-alt-tab.exe 하나만 받습니다.
  2. 실행 — 받은 파일을 두 번 누르면 끝. 설치도, 검은 콘솔 창도 없습니다. 작업 표시줄 오른쪽 트레이에 아이콘이 생기고, 우클릭하면 설정·종료가 있습니다.
  3. 사용 — Alt를 누른 채 Tab·방향키로 고르고, Alt를 놓으면 그 창으로 전환됩니다. Esc로 취소합니다.

로그인할 때 자동으로 켜지게 하려면

저장소를 내려받은 뒤, PowerShell을 관리자 권한으로 실행해서:

powershell -ExecutionPolicy Bypass -File scripts\install_admin_autostart.ps1

작업 스케줄러에 등록되어, 다음 로그인부터 UAC 창 없이 자동으로 켜집니다.

Cursor·VS Code를 관리자 권한으로 쓰신다면: 위 자동 실행 등록이 필요합니다. 일반 권한으로 켜진 전환기는 Windows 보안 정책(UIPI) 때문에 관리자 권한 앱이 활성일 때 Alt+Tab을 감지하지 못합니다.

소스로 실행 (개발용)

git clone https://github.com/kuroicode-beep/smart-alt-tab.git
py -3.13 run.py

Python 3.11+ 만 있으면 됩니다 — 표준 라이브러리만 사용하므로 별도 패키지 설치가 필요 없습니다.

접근성

SVIL 저시력 접근성 기준을 따릅니다 — 고대비 다크, 두꺼운 큰 글씨(나눔고딕 ExtraBold), 색상만으로 상태를 구분하지 않고 테두리·텍스트 라벨 병행, DPI 인식, 과한 모션 지양.
