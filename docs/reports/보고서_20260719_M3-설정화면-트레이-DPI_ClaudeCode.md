## 1. 한 일

PRD 마지막 마일스톤. 표준 라이브러리만으로(신규 의존성 없음, `pyproject.toml` `dependencies=[]`
유지) 다음을 구현했다.

- **설정 화면(SVIL §2.1 필수 3항목)**: 글꼴·글자 크기·다국어를 모두 갖춘 설정 창.
  - 글꼴: SVIL 8종 후보 중 **시스템에 실재하는 것만** 노출(현재 3종 — 나눔고딕(ExtraBold
    실제 헤비 컷)·교보손글씨2019·고딕). 각 버튼을 해당 글꼴로 렌더해 미리보기 겸용, 선택 후
    별도 미리보기 줄도 표시.
  - 글자 크기 3단계(작음16/보통18/큼20, 논리 px 기준).
  - 다국어 5종(한국어·English·日本語·中文·Tiếng Việt), 고정 순서, 언어명은 번역 안 함.
  - **선택 즉시 저장·적용**(별도 저장 버튼 없음 — 클릭 수 최소화로 접근성 향상). 선택 상태는
    색만이 아니라 테두리+체크마커 병행.
  - 설정 창 안에 **"업데이트 내역"** 섹션(스크롤 가능, 버전·날짜 모노체 + 요약).
- **트레이 아이콘**: 순수 ctypes(`Shell_NotifyIconW`) — 외부 의존성 없이 구현. 우클릭 메뉴
  (설정/종료), 좌클릭·더블클릭은 설정 바로 열기. 훅 실패와 별개로 실패해도 전환기 자체는
  계속 동작(경고만 출력).
- **DPI 정밀화**: Tk 자체 폰트 스케일은 프로세스 시작 시 한 번(주로 주 모니터 기준) 고정되어
  다중 모니터 간 실시간으로 안 따라온다는 걸 확인, 매 표시(오버레이·설정창)마다 대상 모니터의
  실제 DPI를 조회해 논리 px(96dpi 기준)를 물리 px로 직접 환산하고 Tk **음수 폰트 크기**(=픽셀
  단위)로 그리도록 변경(`win/dpi.py`: `scale_for_point`, `logical_to_physical_px`).
- **설정 영속화**: `%LOCALAPPDATA%\smart-alt-tab\config.json`, 프로세스 재시작 후에도 유지,
  실행 중에는 설정 변경 시 오버레이에 즉시 반영(`Switcher.apply_config`, Font 객체
  `.configure()`로 위젯 재생성 없이 갱신).

## 2. 신규/수정 파일

- `config.py`(신규) — 설정 영속화, SVIL 8종 후보 중 실재 폰트 감지.
- `i18n.py`(신규) — 5개 언어 문자열 테이블(약 15개 UI 키), 폴백 포함.
- `settings_window.py`(신규) — 설정 화면 UI, 업데이트 내역 포함.
- `win/tray.py`(신규) — `Shell_NotifyIconW` 기반 트레이 아이콘(WNDCLASSW 등록·WNDPROC·
  `TrackPopupMenu`).
- `win/dpi.py` — `get_dpi_for_point` 버그 수정(프로토타입 없는 호출·자기참조 hasattr 제거),
  `scale_for_point`/`logical_to_physical_px` 추가.
- `switcher.py` — config·i18n 연동, 표시마다 대상 모니터 DPI로 폰트 재조정.
- `app.py` — config 로드, 트레이·설정창 조립, 언어 변경 시 트레이 메뉴 라벨도 갱신.

## 3. 중요 기술 확인 (실측)

**트레이 아이콘 WNDPROC은 LL 훅과 달리 tkinter 호출이 안전하다.** `Shell_NotifyIconW` 콜백
메시지는 Tk의 mainloop가 이미 돌리는 표준 `DispatchMessage` 경로로 들어온다(Tcl 이벤트 펌프의
정상적인 일부) — `WH_KEYBOARD_LL`처럼 그 바깥에서 비동기 재진입하는 게 아니다. 그래서
`win/tray.py`의 WNDPROC에서 설정창을 직접 열어도(`deiconify()`) 안전하며, 실제로 외부 프로세스
에서 실행 중인 앱에 `PostMessageW`로 트레이 클릭 메시지를 주입해 설정창이 정상적으로 뜨는 걸
확인했다(크래시·행 없음). `CLAUDE.md`에 이 구분을 기록해 향후 혼동을 방지했다.

## 4. 검증 (실측)

| 항목 | 방법 | 결과 |
|------|------|------|
| 상태머신 | 단위 테스트 | 12/12 통과(M3로 무변경 확인) |
| 실재 폰트 감지 | 시스템 폰트 전수 대조 | 8종 중 3종 실재 확인, 나머지 자동 제외 |
| 설정 영속화 | round-trip 저장·재로드 | 일치 확인 |
| i18n | 5개 언어 전체 키 조회 + 존재하지 않는 언어 한국어 폴백 | 정상 |
| Switcher × config × DPI | 실제 렌더(영어/큰글씨, 한국어 재적용) 스크린샷 | 폰트·크기·언어 전환 정상 |
| 설정 화면 렌더 | 실제 렌더 스크린샷(한국어/日本語, 글꼴·크기 전환) | 정상, 자동 높이로 빈 공간 버그 발견·수정 |
| 트레이→실제 tkinter 호출 | 별도 프로세스에서 실행 중인 앱에 `PostMessageW`로 트레이 좌클릭 주입 | 설정창 정상 오픈(제목에 저장된 언어 반영 확인 — 영속화도 함께 증명) |
| **통합 E2E** | 실제 훅+실제 트레이+실제 설정 저장을 한 프로세스에서: 트레이 클릭→설정 열기/닫기→Alt+Tab 오버레이→Alt 놓아 전환 | 전 구간 크래시 없이 정상, 오버레이 실캡처 확인 |

## 5. 알려진 스코프 결정

- 업데이트 내역(`VERSION_HISTORY`)의 버전별 요약 문구는 번역하지 않는다 — 개발자용 기술
  변경 로그로 간주(SVIL "사용자 데이터·글꼴 이름 번역 제외" 정신 확장 적용). UI 크롬(설정
  화면 자체의 라벨·버튼)은 5개 언어 모두 완전히 번역됨.
- 버튼 모서리는 tkinter 위젯 한계로 완전한 radius를 구현하지 않음(테두리+색+체크마커로
  선택 상태 표현, 기존 오버레이 디자인과 동일한 접근).
