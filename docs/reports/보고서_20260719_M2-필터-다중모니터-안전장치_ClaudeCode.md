## 1. 한 일

- **창 필터 정교화**: 소유(owner) 팝업 체인을 정식으로 워크하여
  (`GetAncestor(GA_ROOTOWNER)` → `GetLastActivePopup` 반복, 보이는 창까지 추적) 각 소유
  그룹의 **대표 창 하나만** 목록에 넣는다. 대화상자를 띄운 앱은 대화상자가 대표가 되고,
  숨은 소유창·중복 항목이 사라진다. 기존 도구창·cloaked·무제목 제외 규칙은 유지.
- **다중 모니터 배치**: 오버레이를 **커서가 있는 모니터의 작업영역**(작업표시줄 제외) 중앙
  상단 1/3에 띄운다. `GetCursorPos` → `MonitorFromPoint` → `GetMonitorInfoW(rcWork)`.
  폭은 그 작업영역의 82%(최대 1280)로 고정, 화면 밖으로 넘치지 않는다.
- **안전장치 강화**:
  - **미소비 폴백**: 열린 창이 없으면 Alt+Tab을 소비하지 않아 **기본 Windows Alt+Tab**이
    그대로 동작한다(`_begin()`이 False 반환 → 훅이 통과).
  - **끼임 방지 워치독**: 폴러(~15ms)가 매 틱 `GetAsyncKeyState(VK_MENU)`로 Alt 실제 상태를
    확인해, **세션 중인데 Alt가 놓였으면(=keyup 이벤트 유실) 선택을 자동 확정**한다. 오버레이가
    화면에 남는 사고를 막는 백업 경로(정상 경로는 훅의 Alt keyup).

## 2. 수정 파일

- `win/windows.py` — `_root_owner_representative()` 소유 체인 워크, `_is_alt_tab_window`
  정교화, `cursor_workarea()`·`is_alt_down()` 추가, 관련 Win32 프로토타입·구조체(MONITORINFO).
- `switcher.py` — `cursor_workarea()` 기반 폭·중앙 배치(`_place`), 다중 모니터 대응.
- `controller.py` — `_begin()` bool 반환(미소비 폴백), 폴러 워치독.
- `tests/test_controller.py` — 미소비/워치독 케이스 추가(총 12건).

## 3. 검증 (실측)

| 항목 | 방법 | 결과 |
|------|------|------|
| 상태머신·안전장치 | 단위 테스트 | **12/12 통과** (미소비 폴백, 워치독 발동/미발동 포함) |
| 필터 정교화 | 실제 데스크톱 `list_windows()` | 대표 창만(Tether·Claude·YouTube·D.Y.·카카오톡), 유령/중복 없음 |
| 다중 모니터 배치 | 실앱 오버레이 캡처 | 커서 모니터 작업영역 중앙, 화면 안 완전 표시 |

| 가독성 | 렌더 캡처 | 헤비 폰트(나눔고딕 ExtraBold)로 큰 글씨·고대비 |
